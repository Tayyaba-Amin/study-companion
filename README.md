# Study Companion

An AI-powered learning platform that transforms PDF study materials into interactive learning resources. Upload your notes once and instantly generate summaries, quizzes, flashcards, and chat with your documents using AI.

##  Features

-  Secure user authentication
-  Upload PDF documents
-  AI-generated document summaries
-  AI-generated quizzes (Multiple Choice, True/False, Short Answer)
-  AI-generated flashcards
-  AI chat with uploaded documents
-  Learning dashboard with progress tracking
-  Document management
-  Light & Dark mode
-  Responsive design

## System Architecture

User → Native Builder Frontend → Supabase Backend → Edge Functions → AI/ML API → AI Response → User Interface

Supabase Edge Functions securely communicate with the AI/ML API, process uploaded documents, and return AI-generated summaries, quizzes, flashcards, and chat responses.

---

## Project Overview

Study Companion helps students learn more efficiently by converting uploaded PDF documents into AI-powered study resources. Instead of manually creating notes or quizzes, users can instantly generate summaries, interactive quizzes, flashcards, and ask questions directly about their study material.
